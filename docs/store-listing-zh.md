# cark 应用商店文案（中文）

## 应用名称

cark 论文阅读器

## 一句话简介

把电脑处理好的论文装进口袋，离线读原文、译文、图片与批注。

## 完整介绍

cark 是一款面向深度论文阅读的离线随身书架。

在电脑端完成论文解析和翻译后，导出一个 `.carkpaper` 文献包，通过文件管理器、网盘、微信、数据线或系统分享发送到 Android 手机和平板。导入完成后，不连接电脑、不登录账号、没有网络也能继续阅读。

主要功能：

- 离线阅读结构化原文和已有双语译文
- 保留论文目录、图片、公式与表格
- 记录阅读进度，切换未读、阅读中和已读状态
- 收藏、标签、搜索和最近阅读
- 划线批注、回复、编辑、归档与删除
- 校验文献包身份、版本、大小和资源完整性
- 从文件选择器、系统“打开方式”或分享菜单直接导入
- 单篇删除、全部清理和本机空间查看
- 可选连接用户自己的 cark 电脑端

cark 移动端没有广告，不集成行为分析 SDK，当前版本不提供账号或云同步。论文、批注和阅读位置默认保存在当前设备中。

## 1.0.0 更新说明

- 上线 Android 离线论文书架
- 支持 `.carkpaper` 文献包选择、打开方式和系统分享导入
- 支持本机阅读进度、收藏、标签和批注
- 新增本机空间管理、文献删除与隐私说明
- 支持可选的个人电脑 HTTPS 连接

## 数据安全表填写依据

- 是否创建账号：否
- 是否含广告：否
- 是否使用分析或广告标识符：否
- 是否向开发者服务器收集论文、批注或阅读行为：否
- 是否在设备外处理数据：仅当用户主动填写个人 HTTPS 地址并连接自己的电脑时
- 是否允许用户删除本机数据：是，支持单篇和全部删除
- 传输加密：个人电脑连接仅允许 HTTPS
